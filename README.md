## Project Descriptions

### Supervised Learning Project (`supervised_ml.py`)
This project demonstrates **Linear Regression** using `scikit-learn`. It trains a model on historical data (years of experience vs. salary) to learn the underlying linear relationship and predict the expected salary for a professional with a given number of years of experience.

### Unsupervised Learning Project (`unsupervised_ml.py`)
This project demonstrates **K-Means Clustering** using `scikit-learn`. It groups unlabelled customer data points into clusters based on behavioral similarities, allowing businesses to segment customers without pre-existing target categories.
